Bildschirm

Schließe ein echtes Mini-Display an deinen micro:bit an und programmiere deine eigene Boot-Animation — mit Ladebalken, Kreisen und Linien wie bei einem richtigen Computer!

🎯
Lernziel
Am Ende zeigt dein OLED-Display eine komplette Boot-Sequenz: Ein Ladebalken füllt sich, Kreise und Linien tanzen über den Bildschirm, und zum Schluss erscheint dein fertiges Bild mit „READY!".

🛠️ Schritt-für-Schritt Verkabelung
Schwarzes Kabel: OLED GND → micro:bit GND
Masse/Erdung — immer zuerst verbinden!
Rotes Kabel: OLED VCC → micro:bit 3V
Das Display braucht 3,3 V Stromversorgung.
1. gelbes Kabel: OLED SCL → micro:bit P19
Takt-Leitung — gibt den Rhythmus für die Datenübertragung vor.
2. gelbes Kabel: OLED SDA → micro:bit P20
Daten-Leitung — hierüber schickt der micro:bit die Bilder zum Display.
💡
Display bleibt schwarz?
Meistens sind SCL und SDA vertauscht — tausche die beiden gelben Kabel. Und denk daran: P19 und P20 sind winzige Kontakte am Goldrand, du brauchst dafür das Breakout-Board. Krokodilklemmen funktionieren hier nicht!
2

Programmieren

Jetzt kommt der Code — deine eigene Boot-Animation.

Für das OLED-Display brauchst du eine Extension in MakeCode — ein Zusatzpaket mit allen Zeichen-Blöcken. Die Installation dauert nur eine Minute.

🔧 Extension installieren (einmalig pro Projekt)
1
Klicke in MakeCode auf „Erweitert" ganz unten in der Kategorieliste.
2
Klicke auf „+Extension" (ganz unten).
3
Suche nach „oled-ssd1306" oder gib direkt diese URL ein:
https://github.com/tinkertanker/pxt-oled-ssd1306
4
Klicke auf die Extension „oled-ssd1306" → sie erscheint als neue türkise Kategorie „OLED".
1
Display starten
Füge im „beim Start"-Block den Block „initialize OLED with width 128 height 64" aus der OLED-Kategorie ein. Ohne diesen Block bleibt das Display schwarz!
2
Boot-Text und Ladebalken-Rahmen
Füge „show string" mit dem Text SYSTEM BOOT... ein. Danach zeichnest du den leeren Rahmen für den Ladebalken: „draw rectangle from: x0 y0 to x1 y1" mit den Werten 10, 30 bis 118, 45.
3
Ladebalken flüssig auffüllen
Jetzt kommt der Trick: eine „für index von 0 bis 108"-Schleife. Darin zeichnest du jedes Mal ein Rechteck von 10, 30 bis 10 + index, 45 — dafür brauchst du den Plus-Block aus Mathematik. Dazu eine „pause (ms)" von 2. So wächst der Balken Pixel für Pixel!
4
Wachsende Kreise
Warte kurz („pause (ms)" mit 300), lösche das Display mit „clear OLED display" und zeige GRAFIK-ENGINE:. Dann eine „für index von 1 bis 15"-Schleife: Zeichne mit „draw circle at x: 64 y: 40 radius" einen Kreis mit Radius index × 2 (Mal-Block aus Mathematik) und warte 50 ms. Der Kreis pulsiert nach außen!
5
Linien-Fächer
Gleich danach eine „für index von 0 bis 8"-Schleife: Zeichne mit „draw line from: x: 0 y: 0 to x: … y: 64" eine Linie — als Ziel-x nimmst du index × 16. Mit 50 ms Pause entsteht ein Fächer-Effekt.
6
Das finale Bild: READY!
Noch eine „pause (ms)" von 1000, Display löschen, dann „show string" mit READY!. Jetzt baust du dein Bild: ein großer Rahmen mit „draw rectangle" von 0, 0 bis 127, 63, ein Auge in der Mitte mit „draw filled circle at x: 64 y: 32 radius: 10" und zwei Kreuzlinien mit „draw line": von 0, 32 nach 128, 32 und von 64, 0 nach 64, 64.
MakeCode Editor öffnen
In MakeCode öffnen

Vergiss nicht: Extension installieren bevor du anfängst zu programmieren!

  • Koordinaten verstehen: Der Punkt 0, 0 ist oben links. x geht nach rechts (bis 127), y nach unten (bis 63) — anders als in Mathe!
  • Der „initialize OLED"-Block muss ganz am Anfang stehen — sonst passiert gar nichts.
  • Display bleibt schwarz? Prüfe die gelben Kabel: SCL muss an P19, SDA an P20.
  • Abkürzung gefällig? Es gibt auch einen fertigen Block „draw loading bar at … percent" — aber mit der Schleife lernst du, wie Animationen wirklich funktionieren.
⚠️ Versuche es zuerst selbst — die Lösung ist nur zur Kontrolle!
Aufbau des Programms (im „beim Start"-Block)
beim Start
initialize OLED with width 128 height 64
show string "SYSTEM BOOT..."
draw rectangle from: x0 10 y0 30 to x1 118 y1 45
für index von 0 bis 108
draw rectangle from: x0 10 y0 30 to x1 10 + index y1 45
pause (ms) 2
pause (ms) 300
clear OLED display
show string "GRAFIK-ENGINE:"
für index von 1 bis 15
draw circle at x: 64 y: 40 radius: index × 2
pause (ms) 50
für index von 0 bis 8
draw line from: x: 0 y: 0 to x: index × 16 y: 64
pause (ms) 50
pause (ms) 1000
clear OLED display
show string "READY!"
draw rectangle from: x0 0 y0 0 to x1 127 y1 63
draw filled circle at x: 64 y: 32 radius: 10
draw line from: x: 0 y: 32 to x: 128 y: 32
draw line from: x: 64 y: 0 to x: 64 y: 64
